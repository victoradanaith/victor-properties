# ราคาตึกแถวราชเทวี

เว็บแอปเก็บข้อมูลอสังหาฯ รอบ BTS ราชเทวี ใช้เป็นราคาอ้างอิงตึกแถว

- **เป้าหมายหลัก:** ประเมินเรตตลาดของทรัพย์หลัก (ตึกแถวใกล้ปั๊ม LPG)
- **เป้าหมายรอง:** หาตึกแถวราคาต่ำกว่าตลาด มารีโนเวทแล้วขายหรือปล่อยเช่า แข่งกับตลาดคอนโด
- **เป้าหมายรอง:** ดูกลุ่มลูกค้านิสิตจุฬาฯ เทียบค่าเช่าห้องและหอพักรอบจุฬาฯ และคำนวณผลตอบแทนถ้าแบ่งห้องให้นิสิตเช่า

## ใช้งาน

แอปตัวจริงเปิดที่ <https://claude.ai/artifact/4duHy5ovVgHm3BxNJTDeNg> (เปิดได้เฉพาะเจ้าของ และคนที่เจ้าของแชร์ให้)

- **ภาพรวม:** แผนที่ปักหมุด กราฟราคาต่อ ตร.ว. เทียบระยะทาง และราคากลาง
- **รายการทั้งหมด:** เพิ่มหรือแก้ประกาศได้ 6 ประเภท (ตึกแถวขาย, ขายแล้ว, ให้เช่า, คอนโดขาย, คอนโดเช่า, ห้องเช่า/หอพักรายเดือน) พร้อมระยะห่างจาก BTS ราชเทวีและจุฬาฯ
- **หาดีล:** จัดอันดับตึกที่ราคาต่ำกว่าตลาด พร้อมต้นทุนรีโนเวทเทียบคอนโด
- **ทรัพย์หลัก & สมมติฐาน:** ข้อมูลตึกแถวใกล้ปั๊ม LPG และตัวเลขที่ใช้คำนวณ

ฉบับอ่านอย่างเดียวบน GitHub Pages: <https://victoradanaith.github.io/victor-properties/> ใช้ข้อมูลจาก `data/snapshot.json` ซึ่งไม่รวมรายการจาก Google Sheet ส่วนตัว ไม่มีชื่อหรือเบอร์ผู้ติดต่อ และไม่มีหมุดหรือข้อมูลทรัพย์หลัก (ระยะทางวัดจาก BTS ราชเทวีแทน) ถ้าจะอัปเดตฉบับนี้ ให้ export ฐานข้อมูลของแอปแล้วรัน `python3 tools/build_pages.py <export_dir>`

## ไฟล์ในรีโป

| ไฟล์ | คืออะไร |
|---|---|
| `ratchathewi-shophouse.html` | โค้ดหน้าแอป (HTML + JS, ใช้ Leaflet จาก cdnjs) |
| `index.html`, `data/snapshot.json` | ฉบับ GitHub Pages สร้างจาก `tools/build_pages.py` |
| `assets/ratchathewi-map-z17.jpg` | ภาพแผนที่ย่านราชเทวี ต่อจาก OpenStreetMap ซูม 17 ตอนเผยแพร่จะใช้ชื่อไฟล์ `ratchathewi-map-z17.jpg` |

ข้อมูลประกาศไม่ได้อยู่ในรีโปนี้ แต่อยู่ในฐานข้อมูลของ artifact (collection `listings` และเอกสาร `settings/main`) สำเนาประกาศที่หามาได้อยู่ใน Google Sheet แท็บ "ประกาศจาก Claude"
